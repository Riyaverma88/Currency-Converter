🧩 Project overview
A simple and responsible web application allows users to convert between different currencies using real -time exchange rates. Built with HTML, CSS and JavaScript

🚀 Features
.Change between many currencies

.Real -time exchange courses using a public API.

.Easy use and responsible design



🛠 Used technologies
Html5 - to structure the page

CSS3 - for style and layout

Javascript - to get API data and dynamic functionality
